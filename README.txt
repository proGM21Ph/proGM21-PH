PROGM21 SITE - GITHUB VERSION (with owner-only admin)

FILES
 index.html  the website (do not edit)
 site.js     all text, prices, contacts, photo paths (admin edits this)
 admin.js    owner-only admin
 images/     photos, videos, PDF

UPLOAD TO GITHUB
1. github.com > New repository > name it (e.g. progm21), Public > Create.
2. "uploading an existing file" > drag ALL files and the images folder > Commit.
3. Settings > Pages > Branch: main, folder / (root) > Save.
   Your site: https://YOURNAME.github.io/progm21/

CREATE YOUR PRIVATE ADMIN TOKEN (once)
1. GitHub > profile picture > Settings > Developer settings >
   Personal access tokens > Fine-grained tokens > Generate new token.
2. Repository access: Only select repositories > choose your site repo.
3. Permissions > Repository > Contents: Read and write. Generate and copy the token.

LOG IN AS ADMIN
Open https://YOURNAME.github.io/progm21/#admin
Enter owner/repo and paste the token. An Admin button appears (only in your browser).
Edit text, prices, photos > Save and publish. The site updates in 1-2 minutes.

WHY ONLY YOU CAN CONTROL IT
Visitors never see an Admin button. Saving needs your token, and only you have it.
Never share the token. Use "Log out" on shared computers.
